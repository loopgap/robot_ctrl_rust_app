# PRD: PySide6 GUI for sim_platform

## 1. 产品目标

将 sim_platform 的用户界面从 Textual TUI 全面迁移至 PySide6 GUI，实现：
- **启动速度**: < 1 秒（从 <3 秒降至 <1 秒）
- **视觉效果**: 现代化桌面应用风格，原生控件 + 自定义主题
- **交互体验**: 鼠标 + 键盘双模式，拖拽面板，实时图表
- **功能完整**: 100% 迁移现有 TUI 功能 + 新增 GUI 独有功能

## 2. 用户故事

| # | 用户故事 | 优先级 |
|---|---------|--------|

| U2 | 作为研究员，我想通过拖拽面板自定义布局，同时查看多个数据维度 | P0 |

## 5. 技术约束

| 约束 | 说明 |
|------|------|
| 框架 | PySide6 6.11+ (Qt 6) |
| 图表 | QtCharts (QChart + QChartView + QLineSeries) |
| 异步 | QThread + Signal/Slot（不阻塞 UI 线程） |
| 主题 | QSS 样式表（Catppuccin Mocha 配色） |
| 仿真核心 | 保持现有 models/ 接口不变，GUI 仅调用 |
| 数据格式 | HDF5 (h5py) + CSV (pandas 可选) |
| 启动性能 | < 1 秒（懒加载非核心模块） |
| 兼容性 | Python 3.13+, Windows 11 |
