# TUI启动指南

## 快速启动

```bash
# 1. 进入项目目录
cd D:\Workbuddy\2026-05-31-01-59-37\sim_platform

# 2. 激活虚拟环境
.venv\Scripts\activate

# 3. 启动TUI
python -m sim_platform --tui
```

## 或者一行命令

```bash
cd D:\Workbuddy\2026-05-31-01-59-37\sim_platform && .venv\Scripts\python.exe -m sim_platform --tui
```

## 快捷键说明

| 按键 | 功能 |
|------|------|
| `R` | 运行仿真 |
| `C` | 配置参数 |
| `S` | 参数扫描 |
| `F1` | 上下文帮助 |
| `Q` | 退出 |
| `Esc` | 返回上级 |
| `Ctrl+H` | 返回主页 |
| `Tab` | 切换焦点 |
| `Enter` | 确认选择 |
